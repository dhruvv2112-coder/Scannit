# Viewer artifact manifest — proposal to Account 2

Status: **PROPOSAL** (account 3, 2026-11-03). One fixture and one set of routes, so we don't end up with divergent local schemas. The viewer adopts whatever Account 2 publishes in `schemas/v0/`; until then it reads exactly this shape.

## Field meanings
| Field | Rule |
|---|---|
| `uri` | Browser-loadable `https://` URL (signed is fine) or a path relative to the manifest. `s3://`/`gs://` are refused: the API must sign them. |
| `sha256` | Hash of the exact GLB bytes. The viewer refuses to display a file that doesn't match. |
| `mime_type` | `model/gltf-binary` only. PLY/OBJ stay pipeline intermediates. |
| `transform_4x4` | Row-major, affine, maps `source_frame_id` (GLB node space, +Y up) → `target_frame_id` (scene, +Z up). Must be rigid with unit scale; the viewer reports any scale, shear or mirror and never compensates for it. |
| `bounds_m` | Axis-aligned, in `target_frame_id`, meters. The viewer compares it against the geometry and warns if they differ by more than 1 cm. |
| `unit` | `m` (also accepts `METRES`). Anything else is refused, never converted. |
| `scale_status` | `arbitrary` \| `metric_unvalidated` \| `metric_validated` (same enum as `schemas/v0` ScaleStatus). The "Verified metric scale" badge shows only for `metric_validated` **and** no integrity issues. |
| `reference_lengths` | Optional. Endpoints in a named frame. The viewer checks that each endpoint lies on a delivered vertex (within 1 mm) and that `length_m` equals the endpoint distance. This checks software scale only; surveyed checkpoint accuracy is reported by Account 1. |
| `dataset_id`, `job_id`, `synthetic`, `fidelity_warnings` | Provenance, shown in the viewer. `synthetic: true` is always flagged. |

Mapping to PR #1's `mesh_artifact`: `checksum.value` → `sha256`, `media_type` → `mime_type`, `bbox` → `bounds_m`, `units` → `unit`. The transform is new: PR #1 has `frame.up_axis` but no explicit matrix to GLB space.

## Proposed routes (PR #3's API has only `/healthz` today)
| Route | Returns |
|---|---|
| `GET /v0/jobs` | `[{ id, project_id, label?, status, progress_pct, error_message }]`, where `status` is `scannit_schemas.JobStatus` |
| `GET /v0/jobs/{id}` | One job, same shape |
| `GET /v0/jobs/{id}/artifacts/viewer` | The manifest above; `404` until the GLB exists |

CORS: allow `GET` from the viewer origin. Signed URLs should live at least 15 minutes; the viewer reports 403/410 as "expired" and offers Retry.
